# Scientific discrepancies and preserved behavior

These issues were identified before refactoring and are not methodological changes made by this release.

0. **AG News uniform-random drop display.** Both uploaded AG News tables show a mean drop of `0.01` pp. The unrounded result and original analysis give `0.004999999999999449` pp, which existing two-decimal Python formatting renders as `0.00`. The new generator retains `0.00` and records the two display differences in `paper/display_discrepancies.json`; it does not round intermediate seed values or alter the calculation.
1. **Identity controls bypass the episode manager.** All 30 CIFAR fixed-1.0 runs use `control_mode=baseline`, with an inactive `episode_length=100` and no episode logs. AG News neutral runs likewise use ordinary AdamW and an inactive 100-step setting. Other supported intervention policies use 200-step episodes. The conceptual table's statement that all policies share episode boundaries and intervention implementation is therefore not literally true for neutral controls. Raw metadata and training behavior remain unchanged. The current baseline CLI normalizes absent action lists to identity lists `[1.0]`/`[0.0]`; those fields are inactive for the bare optimizer.
2. **UCB denominator.** The submitted equation uses `N + epsilon`, while the inspected `pulseopt==0.1.5` implementation uses `max(N, epsilon)`. Reconcile the manuscript with the generating library version; do not silently change the controller. The exact package version is not recorded for every historical run.
3. **Historical environment provenance is incomplete.** 130 selected results lack a top-level runtime metrics block. The present lockfile establishes the reproduction environment, not proof of the environment used for every archived training run. New training wrapper runs write package versions and the code commit to a separate provenance record.
4. **AG News defaults differ from the paper.** The inherited general runner default is three epochs with no decay. Paper configurations explicitly specify five epochs and `warmup_linear` with zero warmup, which implements linear decay. Defaults remain unchanged; use the manifest-driven training entry point.
5. **AG News cache identity is incomplete.** Tokenized cache naming does not include tokenizer/model revision or maximum length. Paper commands retain the recorded length 128 and split/noise seed 42. A future cache-format correction must be treated separately and must not silently replace existing prepared data.
6. **Approximate FLOPs use an inherited two-class head estimate.** The shared DistilBERT accounting helper originated with SST-2 and still uses two labels. AG News training uses a four-class model. FLOPs do not enter this paper's reported outcomes; the numerical accounting is preserved. Changing that approximation belongs in a separate change.
7. **Inference remains descriptive.** Best fixed is selected once from all five seeds and held fixed inside bootstrap resampling. FM donor sets overlap across target seeds. Neither selection-adjusted inference nor an independent FM sample is introduced by this refactor.

CIFAR's official test split is the reporting/selection validation split, with no untouched test estimate. AG News uses a fixed 90/10 split of the original training data, and the official test split does not supply paper metrics. Peak means the maximum logged validation accuracy, with the earliest maximizer used for peak epoch. Neither runner persists model checkpoint files; the paper's retrospective checkpoint-selection language refers to logged epoch outcomes.

The supplied manuscript still links to `aees-thesis-experiments`. Update that link only after the paper repository and its results release have been published.
